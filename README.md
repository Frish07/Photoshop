# PixelForge

Нативный растровый редактор для Windows 10 и 11 на C++20. В рабочем пространстве по образцу Photoshop инструменты находятся слева, параметры и вкладки сверху, холст с линейками по центру, цвет, слои и история справа. При запуске открывается демонстрационный документ из четырёх слоёв.

## Запуск

Локальная сборка создаёт `build\PixelForge.exe`. Можно запустить её напрямую или перетащить изображение на окно. Готовая сборка x64 публикуется в артефактах [GitHub Actions](https://github.com/Frish07/Photoshop/actions) под именем `PixelForge-Windows-x64`.

Для сборки с CMake и Visual Studio с компонентом «Разработка классических приложений на C++»:

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
.\build\Release\PixelForge.exe
```

Для MSYS2 UCRT64 с GCC достаточно PowerShell:

```powershell
.\build.ps1 -Test
.\build\PixelForge.exe
```

Если MSYS2 установлен в другой каталог, передайте `-Toolchain` с путём к его папке `ucrt64in`.

## Редактирование

- **Слои** — создание, дублирование, переименование, перетаскивание, видимость, блокировка, непрозрачность и семь режимов наложения. Нажмите кнопку маски под списком слоёв и выберите её миниатюру. Чёрная кисть скрывает пиксели, белая восстанавливает.
- **Инструменты** — перемещение (**V**), прямоугольное выделение (**M**), кадрирование (**C**), пипетка (**I**), кисть (**B**), ластик (**E**), градиент (**G**), заливка (**K**), растровый текст (**T**), прямоугольник (**U**), эллипс (**O**), рука (**H**) и масштаб (**Z**).
- **Холст** — размер изображения и холста, поворот на 90°, отражение, кадрирование, яркость, контраст, обесцвечивание, инверсия и Box Blur.
- **Навигация** — колесо масштабирует относительно курсора, пробел и перетаскивание перемещают холст. **Ctrl+0** вписывает изображение в окно, **Ctrl+1** включает 100%, **Tab** скрывает боковые панели. **Ctrl+Z** отменяет, **Ctrl+Shift+Z** повторяет изменение. Вкладка **History** позволяет перейти к сохранённому шагу.
- **Файлы** — **Ctrl+S** сохраняет редактируемый проект в PXF. **File → Export** записывает PNG, JPEG, TIFF, BMP и PSD. Открытие растровых форматов использует установленные кодеки Windows. В многостраничных и анимированных файлах открывается первый кадр.

### Совместимость с Photoshop

PSD поддерживает обычные растровые слои 8-битных RGB и Grayscale файлов с Raw или PackBits RLE. Для слоёв со смарт-объектами, эффектами, группами, масками и другими неподдерживаемыми данными редактор пытается открыть совместимое сводное изображение. PSD-экспорт сохраняет растровые слои, положение, видимость, непрозрачность и поддерживаемые режимы наложения. Пиксельные маски при экспорте в PSD объединяются с альфа-каналами соответствующих слоёв. Для дальнейшего редактирования масок используйте PXF.

Для компоновки и формата файлов использованы материалы Adobe. [Рабочее пространство Photoshop](https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/workspace-overview.html) · [Спецификация PSD](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)

## Память

- Пустая область слоя не выделяет пиксельный буфер. Заполненные области хранятся в плитках 128 × 128. Дублированные слои и состояния истории разделяют неизменённые плитки в памяти. PXF сохраняет совместное использование плиток между слоями.
- История ограничена 80 состояниями и оценочным бюджетом 96 МиБ на документ. Большое изменение может вытеснить старые состояния. Активные пиксели слоёв учитываются отдельно.
- Direct2D рисует видимую часть холста. Масштабированный предпросмотр кешируется по плиткам. Кисть пересчитывает только пересекающиеся плитки.
- Экспорт растровых форматов собирает композицию полосами. Одна сторона холста может достигать 16 384 пикселей. Для импортируемых растровых изображений действует предел 128 Мп. Для PXF предел уникальных пиксельных плиток составляет 1 ГиБ.

Для проверки памяти и скорости запустите `PixelForgeTests.exe --benchmark` из каталога сборки.

Фотография демонстрационного документа создана встроенным ImageGen и находится в `resources/coastal-road.jpg`.
